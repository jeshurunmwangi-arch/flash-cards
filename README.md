# flash-cards

## Descripyion
This is a flashcard web app that allows users to create and save  flashcards.
The flashcards are saved using local storage so they remain after refreshing the page.

## features
- Add flashcards
- Show possible answers
- Save flashcards in local storage
- Delete flashcards when done

## Technologies Used
- HTML
- CSS
- JavaScript
- LOcalstorage

## Setup
1. Clone the repository 
    git clone https://github.com/jeshurunmwangi-arch/flash-cards
 2. Open the project folder

 3. Open index.html in browser
